//Рабочая папка, индекс и коммит
Рабочая папка-это файлы проекта, с которыми я работаю непосредственно.
Индекс-это область, куда я добавляю изменения, которые должны попасть в следующий коммит.
Коммит—это сохранённая версия изменений в истории git.

//Git и GitHub
Git-это распределённая система контроля версий, которая хранит историю изменений проекта локально.
GitHub-это веб-сервис для хранения Git-репозиториев и совместной работы с ними.
Git может работать без GitHub, потому что история проекта хранится локально.
Команда `git diff` показывает изменения в рабочей папке, которые ещё не добавлены в индекс.
Команда `git diff --staged` показывает изменения, уже добавленные в индекс и подготовленные для следующего коммита.

//Использованные команды

`git status` показывает текущее состояние рабочей папки и индекса.
`git diff` показывает изменения в рабочей папке, которые ещё не добавлены в индекс.
`git diff --staged` показывает изменения, которые уже находятся в индексе и попадут в следующий коммит.

// Ветки

Ветка-это отдельная линия разработки в Git, которая позволяет создавать изменения независимо от другой ветки.
При создании нового коммита текущая ветка перемещается на этот новый коммит.
Слияние объединяет изменения одной ветки с другой. После слияния история изменений становится доступна в целевой ветке.
